## Reporting a Vulnerability

For normal bugs, feature requests, and minor fixes, please report them by opening a standard issue in this repository.

### Urgent or Important Vulnerabilities

If you have discovered a very important, critical, or urgent security vulnerability, please **do not** open a public issue. 

Instead, send a detailed report directly via email to:
**suvan.gowrishanker.204@gmail.com**

We will review the vulnerability and respond to your email as quickly as possible to coordinate a fix before any public disclosure.
